# heliox

A solar physics toolkit for Python, built on top of `astropy`, `numpy`, `scipy`,
`matplotlib` and `pandas`.

`heliox` provides the data types and coordinate machinery you need to work with
solar images and solar time series: a coordinate-aware `Map` for 2D solar
imagery, a `TimeSeries` for instrument light curves, a full set of solar
coordinate frames plugged into `astropy.coordinates`, and the ephemeris,
rotation and visualization helpers that tie them together.

## Status

Early development. The API is inspired by — but not identical to — SunPy.
